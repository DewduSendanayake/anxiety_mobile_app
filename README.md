# anxiety_mobile_app
Lightweight Flutter app focused on usage, sensor, and background monitoring
utilities. This repository contains the mobile app source and platform
integration for Android, iOS, web, and desktop targets (where supported).

Key libraries used (see [pubspec.yaml](pubspec.yaml)):
- `geolocator`, `sensors_plus`, `battery_plus` — device sensors & status
- `usage_stats`, `call_log`, `telephony` — usage, call and SMS access
- `flutter_background_service`, `flutter_local_notifications` — background
	execution & local notifications
- `shared_preferences`, `http` — local storage and networking

Quickstart
1. Install Flutter SDK (see https://docs.flutter.dev/get-started/install).
2. From the project root, fetch dependencies:

```bash
flutter pub get
```

3. Run on a connected device or emulator:

```bash
flutter run
```

Common tasks
- Analyze and lint: `flutter analyze`
- Run unit/widget tests: `flutter test`
- Format code: `dart format .` or `flutter format .`
- Build release (Android): `flutter build apk --release`
- Build iOS: `flutter build ipa` (macOS required)

Platform notes
- Android: `local.properties` is generated by the Android tooling and
	contains local SDK paths — do not commit it. Signing keys (JKS) are
	intentionally excluded via `.gitignore`.
- iOS: CocoaPods artifacts live under `ios/Pods/` and are ignored by
	`.gitignore`.

Development tips
- Use an IDE (Android Studio / VS Code) with the Flutter plugin for a
	faster dev loop and device management.
- If you add native capabilities (permissions, services), remember to
	update platform manifests: `android/app/src/main/AndroidManifest.xml`
	and `ios/Runner/Info.plist`.
